## 运行

在仓库根目录的 MATLAB 中执行（只需基础 MATLAB，不需要 Simulink、Python 或额外工具箱）：

```matlab
addpath('SAGE','SAGE/validation');
report = run_sage_tests();                  % 10 组确定性回归检查
results = run_sage_validation;              % 5 个 SNR，每个 20 次噪声实验
% 快速调试版本：run_sage_validation('quick-results', 2)
```

完整实验内部也会运行回归检查。默认结果目录为 `SAGE/validation/results/`。
CSV 包含真值/估计值、逐次误差、迭代 SSE、RMSE 和停止比例；MAT 保存参数、导频、历史和版本；
PNG/PDF 包含四种参数误差随迭代变化、残差与参数步长曲线、RMSE–SNR 曲线。
固定随机种子；噪声试验在同一个已知 QPSK 导频上独立重复。改变导频的泛化尚未测试。
输出目录若已存在，会替换同名数据/图形，diary 日志会追加。

## 模型、约定与单位

对接收阵元 m=0,...,M-1 和样本 n=0,...,N-1：

\[
y_m[n]=\sum_{l=1}^{L}\alpha_l e^{j2\pi m d\cos\phi_l}
 e^{j2\pi\nu_l n/f_s}u[n-k_l]+w_m[n],\quad k_l=\operatorname{round}(\tau_l f_s).
\]

| 变量 | 含义 / 单位 / 维度 |
|---|---|
| `u` | 已知复基带导频；N 个样本，内部转为列向量 |
| `y` | N×M；每列一个接收阵元，不允许用共轭转置改变排列 |
| `s(theta,u,sys)` / `xel(...)` | M×N；每行一个接收阵元 |
| `theta(l).tau` | 时延，秒；实际模型只保留整数采样点 |
| `theta(l).phi` | 相对于 ULA 轴线的到达角，弧度；采用 cos，而非 broadside 的 sin |
| `theta(l).fdopp` | Doppler，Hz；允许负数；相位参考为整个记录的 n=0 |
| `theta(l).amp` | 复电压增益；幅值和相位都要估计，不是功率或 dB |
| `sys.d` | 阵元间距除以波长；不是米 |
| `sys.I, Ta, Tf` | 观测窗数量、窗长、窗起点间隔；Ta/Tf 单位为秒 |
| `sys.L` | 假定已知的路径数；本实现不自动选择模型阶数 |

窗长 `Na=round(Ta*fs)`，窗起点间隔 `Nf=round(Tf*fs)`。
使用的零基样本集合为 Ω = ∪ᵢ {iNf,...,iNf+Na−1}。
不重置各窗口的时间原点。重叠窗口及越界窗口直接报错，避免重复计数或无效访问。
未观察的样本不参与似然或增益归一化。延迟使用零填充，不是循环移位。
独立同分布圆对称复高斯噪声下，最大似然等价于最小化 Ω 上的残差平方和。

## SAGE 更新与停止条件

处理第 l 条路径时，把其他路径的**最新估计**从观测中减掉：

\[
X_l=Y-\sum_{q\ne l}S_q(\widehat\theta_q).
\]

这是 beta=1 的单路径隐数据选择。设单位增益原子为 A(τ,φ,ν)，Frobenius 内积为
z=⟨A,X_l⟩=Σ conj(A)·X_l，E=⟨A,A⟩，则

\[
\widehat\alpha=z/E,\qquad
\min_\alpha\|X_l-\alpha A\|_F^2=\|X_l\|_F^2-|z|^2/E.
\]

因此每个坐标按 **|z|²/E** 选取候选，并更新复增益。不能一般地用 `sum(u.^2)`，
也不能在有限观测、延迟截断或非恒模导频时用全记录平均功率代替 E。
只有候选原子能量相同时，最大化 |z| 才等价。

依次搜索 τ、φ、ν，并立即更新对应的路径残差；每次搜索都包含当前坐标，
防止初始参数不在网格上时被强制跳到更差的候选。并列最大值保留当前坐标。
局部最小二乘残差若因浮点误差增加，则拒绝该路径更新。
这给出非增 SSE 的广义 SAGE/坐标更新，不保证非凸问题的全局最优或真值恢复。

一次完整路径扫描后记录 Jₖ 和

\[
r_k=|J_{k-1}-J_k|/\max(J_{k-1},\epsilon\|Y_\Omega\|_F^2),
\]

以及所有路径、全部四类参数的最大归一化改变量。时延用一个采样间隔、角度和 Doppler
用网格最小间隔归一化；复增益用 max(1,‖上一轮增益向量‖₂) 归一化。
同时满足 `tolObjective` 和 `tolParameter`，且达到 `minIter`，才标记 `converged=true`。
`maxIter` 是上限；达到上限不等于收敛。即便判据满足，也只说明数值稳定，不说明估计正确。

初始化继续采用逐路径消除：每提取一条路径立即减去，再搜索下一条。
这里将原有的分阶段近似初始化替换为逐时延批处理的联合角度/Doppler网格搜索，
使初始化和主循环使用同一个有限窗口似然；这是一项明确的算法实现选择，而非两行索引修补。
初始化约为 O(L·Nτ·(M·K·Nν + Nφ·M·Nν))，K 为实际观测样本数。
主循环按三个坐标搜索；未增加连续优化或 AI 模块。

## 已确认的实现错误

| 原位置 | 问题及影响 | 修复 |
|---|---|---|
| SAGE / SAGEinit 的 Doppler 搜索 | 更新 `theta_t(1)`，却读取 `theta_t(l)`；后续路径候选失效 | 对当前路径的局部结构搜索 |
| SAGE 的 distance | 使用循环外 l，且每次覆盖；threshold 未生效 | 全路径四参数尺度化距离 + SSE 双判据 |
| SAGE / SAGEinit 的 xel 调用 | 始终传入初始 theta；后续迭代与逐次消除看不到新参数 | 主循环缓存并更新当前残差；初始化逐路径减去已估计信号 |
| SAGE 的 z 数组 | 500 个时延分数仅覆写前 5 个角度分数；max 可能返回越界角索引 | 每个坐标独立分数数组 |
| xel | `y'` 将复观测共轭 | `y.'` 仅改变维度 |
| zfun / SAGEinit | `c.'` 不共轭，`conj(ud)'` 又把共轭抵消 | 正确使用 cᴴ 及 conj(u_delay) |
| 增益归一化 | `sum(u.^2)` 对复导频错误；init 还使用整套角度矩阵的 norm | 使用对应单位增益原子的实际窗口能量 |
| SAGEinit 的时延近似 | 窗口多一个样本、跨阵元累加重复计数、延迟缓冲区未始终重置 | 统一窗口索引与零填充原子，使用明确的联合网格初始化 |
| signalGenerator | 时长先 round；短记录 t 全为零，Doppler 被消掉 | `t=(0:N-1)'/fs` |
| signalGenerator 噪声 | 仅实噪声，与复基带圆对称噪声假设不一致 | I/Q 各占总方差的一半；保持总 E|w|²=0.2 |
| 搜索范围 | 固定 5 个角度、只有正 Doppler，不能覆盖一般真值 | 公开可配置网格；默认半平面角度和双向 Doppler |

`main.m` 原来以同一接收波形乘相位构造第二阵元：所有路径共享同一个到达角，
且两个阵元噪声完全相关。RicianChannel 的随机时变增益也不是固定 α 加单一 Doppler。
它设置 L=4 而 Rician 延迟仅两项，d=1 还存在空间混叠。这些是原实验的模型/配置问题，
不能靠修复索引解决。本次保留此历史流程并标注用途，以独立已知信道实验验证核心估计器。
`test.m` 的 SAGE 调用原本全部注释，且真值为三条路径、sys.L=4；不能当作通过证据。
`generateCSI.m` 属于后续活动检测的启发式 CSI 生成器，未纳入四参数估计验证。

## 实验设计与不能混淆的限制

默认 fs=1 MHz，6 阵元，d=0.5，20 个 64 us 观测窗，起点间隔 1 ms。
实际使用 1280 个时刻，跨约 19 ms；完整导频长度 19064。
这组设置用于可识别、可重复的单元实验，不代表室内传播几何或真实硬件配置。

| 路径 | τ / us | φ / deg | ν / Hz | α |
|---|---:|---:|---:|---|
| 1 | 2 | 36 | -180 | exp(j0.4) |
| 2 | 6 | 84 | 70 | 0.7 exp(-j1.1) |
| 3 | 11 | 142 | 240 | 0.5 exp(j2.2) |

1. **独立正向模型**：测试不调用估计器的 `s` 或私有原子构造信号，防止生成与估计共享同一错误。
2. **无噪声、真值在网格上**：检查 τ/φ/ν 恢复及复增益误差、重建残差、提前停止。
3. **20 dB 单次轨迹**：记录初始化后及每一轮参数误差与 SSE；路径关联固定为最终排列。
4. **−5/0/10/20/30 dB，默认每点20次**：每次从无真值参与的初始化出发，
   先一对一匹配路径，再计算 RMSE；保留每次每条路径的误差，不仅保留平均值。
   复增益使用 |α̂−α|，同时检测幅度和相位错误。SNR 使用实际观测上的相干叠加信号功率。
5. **无噪声、网格外诊断**：角度、Doppler 和时延偏离网格，时延真值显式采用线性插值。
   这故意制造生成/估计模型不一致；CSV 中的剩余误差不能归因于噪声或一定归因于实现错误。
   线性插值不是新增的物理带限分数延迟模型，也不是估计器支持亚采样精度的证明。
   另有仅角度/Doppler 偏离网格、时延保持整数的对照，输出 `angle_doppler_offgrid.csv`。
   分数时延压力测试可能出现路径分裂/漏检，而不仅是小的量化误差；该失败不会被隐藏。
   线性插值使每个分数延迟波形成为两个相邻整数延迟导频的线性组合，固定 L=3 的整数模型
   因此不再与生成模型等价。收敛判据仍可能满足，但不能据此认定物理路径恢复成功。

收敛图对参数步长使用 1e-12 的显示下限，并明确标注；CSV/MAT 中仍保留实际零值。

原始整数时延模型在 fs=3.2 MHz 时只有 312.5 ns 分辨步长（约93.75 m传播路程差）。
500 个 τ 候选落到相同整数延迟上并不会产生高分辨能力；需要分数延迟波形模型、足够带宽及可识别性分析。
单 ULA 的 cos(φ) 无法分辨完整 0–2π；这里限制到 0–π。d=0.5 的两个端射端点仍有退化，
实验避开端点。d>0.5 会有空间混叠。Doppler 精度与总观测跨度、窗采样模式及 SNR 有关，
窄网格步长不等于同等物理分辨能力。近邻路径、弱路径、错误路径数和随机时变增益均可能影响结果。
网格真值情况下，离散参数在多个 SNR 下 RMSE 恰为零是可能的；不等于连续参数误差为零。
20 次实验用于回归与教学，不构成发表级统计精度或 CRLB 验证；不要把曲线称为普遍性能保证。

## 可配置调用

```matlab
options = struct('tauGrid',(0:12)/sys.fs, ...
    'phiGrid',(10:2:170)*pi/180,'fdGrid',-300:10:300, ...
    'maxIter',40,'minIter',2,'tolObjective',1e-9,'tolParameter',1e-7);
theta0 = SAGEinit(y,u,sys,options);
[theta,history] = SAGE(y,u,theta0,sys,options);
```

未提供时：τ 为 0 到4 us之间可表示的整数采样点，φ 为0:1:180度，ν为−200:5:200 Hz，
最大50轮，最少2轮。`tauGrid` 会去重并量化到整数采样点，`history.options` 返回实际网格。
初始有效坐标可不在网格上，后续搜索仍将它保留为候选；网格定义候选集而非强制投影边界。
